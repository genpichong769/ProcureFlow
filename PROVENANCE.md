# Project provenance

ProcureFlow was independently implemented for the enterprise procurement domain.

The local SmartVoyage course project was used only as a read-only architecture reference during early analysis. Its source, data, prompts, logs, assets, configuration values, and archive are not included in this repository. No license or redistribution notice was present in the local SmartVoyage directory or archive, so no SmartVoyage material is redistributed.

The final comparison covered 34 reference code/configuration files and 134 ProcureFlow code/configuration files. It found no identical non-empty files and no significant shared exact 24-token windows. ProcureFlow uses its own procurement schema, services, rules, tests, prompts, workflow, A2A contracts, and MCP tools.

Dependencies listed in the lock files are third-party works governed by their respective licenses. This repository currently contains no project license file and does not grant an additional reuse license.
